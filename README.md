# Axel Mireles — Personal Portfolio

Personal portfolio built with Next.js App Router, React, TypeScript, Tailwind CSS and Framer Motion.

## Requirements

- Node.js `>=22.13.0`
- npm

## Development

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js (normally `http://localhost:3000`).

## Validation

```bash
npm run build
npx tsc --noEmit
npm run lint
```
